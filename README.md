## 💡 Objetivos do Projeto

**Objetivo geral:**  
Desenvolver um sistema capaz de auditar automaticamente sites públicos brasileiros, identificando dependências tecnológicas e rastreamento de big techs estrangeiras.

**Objetivos específicos:**
1. Detectar scripts e cookies de rastreadores (Google, Meta, Cloudflare, etc.);  
2. Identificar requisições a domínios externos e servidores estrangeiros;  
3. Exibir os resultados em um painel interativo;  
4. Avaliar o grau de dependência tecnológica dos sites analisados.

---

## 📘 Tecnologias e Ferramentas

- **Python 3.x**
- **Requests / BeautifulSoup4**
- **Pandas**
- **TLDExtract**
- **Streamlit / Dash** (para o painel)
- **GitHub** (versionamento)
